# Reporte Final de Capacitación CAPA · Blue Medical

Dashboard para crear, guardar y consultar los reportes de finalización del proceso CAPA (Asesor MultiSkills).

## Funciones
- Panel de colaboradores con búsqueda por nombre, clínica o puesto, y filtros por resultado y clínica.
- Historial de reportes por colaborador.
- Edición directa de datos, resultados por área, desempeño práctico, fortalezas, oportunidades y plan de seguimiento.
- Cálculo automático del promedio y del resultado (aprobado con 80% o más en promedio y evaluación final).
- Descarga en PDF desde el botón "Descargar reporte" (Guardar como PDF).

## Uso
Abre `index.html` en el navegador o publícalo con GitHub Pages.

> Fuera de Claude, los reportes se guardan en el navegador de cada persona (localStorage), por lo que el historial no se comparte entre equipos.
